## V5 PowerContext 记忆复用（真实 Server 1.2.0，非 mock）

Server：`powercontext server run --host 127.0.0.1 --port 8000 --no-env-file`（recallloop-venv 自带 1.2.0；6s 就绪；按 PID 停止）。

第 1 次生成：
```

[brief] written=.../v5-run1.md bytes=3247
```
第 2 次生成（同 topic）：
```
[pc] 历史交接记忆命中 4 条（写入简报头部）
[pc] PowerContext 已记录：entry=mem_ent_a840eea008d345e5af8ac0ea4d8d9781 artifact=handoff
第 9 行：- **历史交接记忆**：PowerContext 命中 4 条相关记录（跨次交接复用），最近一条：交接简报已生成：topic=二手书 交易小程序 校园 支付（agentA→agentB）…
```
产物副本：`demo-brief-powercontext-run1.md` / `demo-brief-powercontext-run2.md`。

> 真实 Server 暴露并修复了两处契约 bug（mock 测不出）：
> ① `create_handoff` 的 `state[*]` 应为 `{text, citations}` 且 citations ≥1（原来传 `summary` / 空列表）→ 422；
> ② 同文本重复 `remember` 会被服务端去重并返回空 citation → 记忆文本加时间戳，使每次交接都是独立事件。
