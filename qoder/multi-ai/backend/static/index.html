多AI协同底座 v2

让不同 agent 快速找到彼此窗口里的环境与产出：一个父进程派工，各 agent 去资料库捞原始证据，父进程判质量、交叉核验、整合，再以可核验的证据交接给下一个 agent。

  • 只读采集 DSH / WorkBuddy / Codex 的真实会话日志，凭据脱敏后归一为语料。
  • seekdb 三路混合检索（向量 + 关键词 + 结构化），每条命中带 file:line 引用；可按文件反查是哪个 agent 改的。
  • PowerContext 作跨 agent 共享记忆与原生交接：交接的每条结论都挂引用，接收方 continue 时服务端逐条核验证据是否可得。

本页无需后端即可浏览；未连接后端时自动进入演示模式（内置真实运行快照）。

解决的 v1 局限

🧵
无共享记忆

各 agent 各记各的，没有共同真相源。v2 用 PowerContext 做跨 agent 账本。

🤝
无跨 agent 交接

换 agent 就断片。v2 用原生交接工件，结论挂引用、服务端核验证据。

🎯
无派工调度

没有父进程分派。v2 拆任务派给真实 agent，判质量不够就换策略重捞。
