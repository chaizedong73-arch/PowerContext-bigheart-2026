# 课程复习笔记：易混概念辨析

本笔记整理三处最容易混淆的概念，用于薄弱点验证。每个概念给出定义、区别与记忆口诀。

## 易混概念一：进程与线程

进程是资源分配的基本单位，拥有独立的地址空间；线程是 CPU 调度的基本单位，同一进程内的多个线程共享地址空间与文件描述符。一个进程崩溃通常不影响其他进程，但一个线程崩溃可能拖垮整个进程。创建线程的开销远小于创建进程，线程间通信可直接读写共享变量，进程间通信则需要管道、消息队列或共享内存等 IPC 机制。记忆口诀：进程管资源、线程管执行。

## 易混概念二：并发与并行

并发（concurrency）指在一段时间内交替处理多个任务，单核 CPU 通过时间片轮转即可实现并发；并行（parallelism）指在同一时刻真正同时执行多个任务，必须依赖多核或多处理器。并发强调结构上同时处理，并行强调物理上同时运行。一个程序可以并发但不并行。记忆口诀：并发是交替、并行是同时。

## 易混概念三：堆与栈

栈由编译器自动分配释放，存放函数参数、局部变量与返回地址，遵循后进先出，速度快但空间有限；堆由程序员手动申请释放（如 malloc 与 free），空间大、生命周期灵活，但容易产生内存泄漏与碎片。栈内存随函数调用结束自动回收，堆内存必须显式释放否则泄漏。记忆口诀：栈自动、堆手动。

## 复习建议

以上三组概念建议在复习时各做一张卡片，自评标记为不会或模糊的，系统会写入薄弱点并在下次优先出题。连续三天正确率低于 60% 的概念，应回到原始讲义重新精读，而不是反复刷题。
