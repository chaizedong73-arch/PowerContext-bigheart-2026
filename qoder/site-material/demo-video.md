## 录制提示

- 录屏工具：Windows `Win + G`（Xbox Game Bar）或 OBS。
- 录制前清空 `qoder/app/data/reviews.json` 与日志，保证从干净状态开始。
- **切勿在视频中暴露任何 token / API Key**；PowerContext 本项目以无鉴权本地模式运行。
