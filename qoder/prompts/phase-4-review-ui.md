# 阶段 4：复习流程与前端 UI

> 前置：阶段 2、3 完成。在 Qoder 中执行后自测并截图存档（本阶段截图将直接用作网站「演示截图」素材，请用真实数据）。

---

把「复习教练 RecallLoop」的四个页面做成完整可用的单页应用，串起「导入 → 问答 → 自测 → 计划」闭环。

## 一、出题功能（后端）

1. 新增 `POST /api/review/cards`：基于已导入资料生成复习卡。
   - 无 Key 模式：从资料块中机械生成——每块提取关键句，问句模板如「关于《{title}》，{挖空的关键词}是？（来源：{source}）」；实现简单挖空（去掉数字、专有名词等）即可，不要求智能。
   - 配置了 LLM Key（环境变量）时可用模型生成，Key 不落盘。
2. 出题优先级：先查 PowerContext 薄弱点记忆（`/v1/memory/search`），薄弱点对应的 `source` 优先出题；否则按块顺序。
3. 新增 `POST /api/review/answer` 扩展：`{"card_id", "result": "pass"|"fail"|"fuzzy"}`，落本地记录并走阶段 3 的 `record_review`。

## 二、前端四页（`qoder/app/static/`）

1. **资料库页**：导入表单（选文件或粘贴文本 + 文件名）、已导入列表（文件名/块数/删除按钮）、导入成功提示。所有列表项展示 seekdb 集合状态。
2. **问答页**：提问输入框；回答区展示融合后的 Top-5 依据卡片（text 摘要 + source/title 出处 + 相关度）；提供「按来源过滤」下拉（选项来自资料列表）。页面标注「检索：seekdb 向量+关键词+结构化混合」。
3. **复习页**：开始复习按钮 → 逐卡展示问题 → 三个自评按钮（会 / 模糊 / 不会）→ 结束显示本次统计（数量、正确率）。页面标注「记忆：PowerContext」。
4. **进度页**：显示「上次复习」（来自 context/prepare 的历史上下文摘要，status=empty 时显示「首次使用，还没有历史记录」）、「今日推荐清单」（来自 /api/plan）、「薄弱点列表」（来自 memory/search 结果）。

## 三、体验要求

- 响应式布局，手机宽度可用（评委可能用手机看）。
- 每个页面右上角放一个「技术说明」小徽标，悬停显示该页用到 seekdb / PowerContext 的哪个能力——这是评委判断「技术真实发挥作用」的第一触点。
- 错误处理：PowerContext Server 未启动时进度页显示友好提示与启动命令，不白屏。
- 无 Key 状态全流程可用（local embedding + 机械出题），不依赖任何付费服务。

## 四、自测（留存截图，后面网站要用）

1. 导入 2 份真实资料（如课程讲义），问答页提问并截图「带出处的回答」。
2. 完成 5 张卡自评（至少 2 张「不会」），截图复习页与统计。
3. 重启应用，进度页出现「上次复习进度」与「今日推荐」，截图——这是跨会话续接的核心证据。
4. 全程不配置任何 API Key，确认可用。
